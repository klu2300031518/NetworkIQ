# NetworkIQ

## Inventory Optimization & Placement Across the Fulfillment Network

**Team ID:037

---

# Project Overview

NetworkIQ is an AI-powered inventory optimization system designed to help
retailers manage inventory across multiple warehouses.

The system analyzes inventory stock and demand information to identify
low-stock situations and generate intelligent inventory recommendations.

It provides a centralized dashboard where users can:

- Monitor inventory across warehouses
- View stock and demand information
- Generate AI-powered recommendations
- Accept or ignore recommendations
- Maintain recommendation history
- View recommendation reports
- Monitor inventory statistics

The system follows a three-tier architecture consisting of a React
frontend, Spring Boot backend, and Python Flask AI service.

---

# Key Features

## 1. Inventory Management

Users can manage warehouse inventory information including:

- Warehouse
- Product
- Stock
- Demand
- Transfer Cost

The inventory data is stored in MySQL and retrieved through REST APIs.

---

## 2. AI Recommendation Engine

The system analyzes inventory conditions and generates recommendations
based on stock and demand.

Example recommendation:

**Recommendation:** Transfer Stock

**Reason:** Low stock detected

**Priority Score:** 325

The recommendation is generated by the Python AI service and returned
through the Spring Boot backend to the React frontend.

---

## 3. Recommendation Decision Management

Users can:

- Generate recommendations
- Accept recommendations
- Ignore recommendations

Accepted recommendations are stored in the recommendation history.

---

## 4. Recommendation History

The system maintains a history of generated AI decisions.

The history contains information such as:

- Warehouse
- Product
- Stock
- Demand
- Recommendation
- Priority Score
- Reason
- Decision
- Date

This allows users to review previous AI decisions.

---

## 5. Reports

The Reports module provides a centralized view of previous AI
recommendations.

It displays:

- Total recommendations
- Accepted recommendations
- High-priority recommendations
- AI decisions
- Recommendation history

---

## 6. Dashboard

The dashboard provides an overview of the inventory system.

It displays:

- Inventory count
- AI recommendation count
- Low-stock items
- Reports
- Total stock
- Total demand
- Accepted AI decisions

The dashboard also provides navigation to the major modules.

---

## 7. Analytics

The system includes an Analytics module for analyzing inventory
information and comparing stock and demand data.
